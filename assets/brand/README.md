# Marca Northum

Arquivos oficiais do logo da Northum (direção visual Norte). O nome está convertido em curvas, então os arquivos não dependem da fonte instalada.

- `svg/`: versões vetoriais, para site, impressão e qualquer tamanho.
- `png/`: as mesmas versões com fundo transparente (logos horizontais com 2000 px de largura, verticais com 1200 px, símbolos, fotos de perfil e ícone com 1024 px).

| Arquivo | Uso |
|---|---|
| `northum-logo-horizontal-fundo-escuro` | Versão principal, sobre meia-noite `#0A1626` |
| `northum-logo-horizontal-fundo-claro` | Sobre gelo `#EEF2F7`, branco ou ouro `#D4A857` |
| `northum-logo-horizontal-branco` / `-preto` | Uma cor só (impressão, gravação) |
| `northum-logo-vertical-*` | Espaços quadrados: capas, crachás, adesivos |
| `northum-simbolo-*` | Só o símbolo, nas quatro cores |
| `northum-perfil-meia-noite` / `-ouro` | Foto de perfil redonda (WhatsApp, Instagram, LinkedIn) |
| `northum-icone-app` | Ícone de app e favicon |

Cores, tipografia, área de proteção, tamanho mínimo e o que não fazer estão no manual de marca da Northum.

Fontes da marca: Sora (títulos) e Inter (texto), ambas gratuitas no Google Fonts.
